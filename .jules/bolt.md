## 2026-07-30 - Pre-compiling Regexes and Memory Use
**Learning:** Pre-compiling regular expressions using `re.compile` at the module level instead of inline in functions can slightly improve performance by reducing overhead, particularly inside tight loops or frequently called functions like `normalize` in data processing pipelines. In this case, extracting inline regexes to module constants in `normalize.py` saved a few milliseconds per 1000 iterations.
**Action:** Always check heavily used text processing functions for inline `re.compile` or `re.sub`/`re.match` with string patterns, and extract them to module level constants if possible. Ensure we respect memory constraints: stateful parsers like `html2text.HTML2Text` must NOT be cached globally or in thread-locals to avoid data leaks in concurrent environments.
