## 2026-07-24 - Pre-compiled Regexes and Thread-Local State Caching
**Learning:** In highly concurrent text-processing pipelines like `ts4k/core/normalize.py`, stateful objects like `html2text.HTML2Text` can be extremely expensive to instantiate repeatedly (~1.15x speedup to cache). However, this app architecture operates in a concurrent environment, so we must avoid caching state globally across threads to prevent data races. Similarly, pre-compiling regular expressions explicitly at the module level rather than repeatedly inline (e.g., in `_remove_hidden_elements` or `_looks_like_html`) provides subtle but measurable speedups when processing thousands of emails.
**Action:** Always pre-compile frequently used regular expressions at the module level. When caching stateful objects to avoid initialization overhead, ensure they are stored in `threading.local()` to maintain thread safety.
