## 2025-03-05 - Avoid in-function regex compilation and use thread-local cache for stateful objects
**Learning:** Compiling regex patterns like `_HTML_TAG_PATTERN` and `_UNSUB_PATTERNS` at the module level instead of within functions provides a substantial performance improvement (up to 7x in targeted functions). Caching stateful formatting objects like `html2text.HTML2Text` helps avoid repeated instantiation overhead (~1.06x speedup). Because the ts4k project may be used in concurrent environments, using `threading.local()` prevents global state issues and ensures thread safety.
**Action:** When identifying recurring processes or stateful object usages inside frequently called functions (like data pipelines and normalization functions), proactively lift regex compilation to module constants, and utilize `threading.local()` to safely cache objects in concurrent contexts.
